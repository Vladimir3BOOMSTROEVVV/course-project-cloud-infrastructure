# Курсовой проект

## Реализация программы контроля облачной инфраструктуры

### 1. Назначение программы

Программа предназначена для анализа телеметрических данных компонентов облачной инфраструктуры.

Программа должна считывать последовательность измерений, анализировать изменение значений компонентов, определять их состояние и обнаруживать инциденты по заданному условию.

Проект разрабатывается на языке C.

---

### 2. Индивидуальный вариант № 8 

Формат телеметрии:

- код компонента: A;
- разделитель: (;);
- порядок данных: время → компонент → значение;
- одна запись может содержать несколько последовательных измерений;
- временная модель: T - номер отсчёта.

Пример входных данных:


1;A;24.5;2;A;25.1;3;A;26.0


Для анализа используется производный показатель - логарифмическое изменение:


Q = ln(X[i]) - ln(X[i-1])


Состояние компонента определяется следующим образом:


NORMAL, если -0.05 <= Q <= 0.05
ALERT, если Q < -0.05 или Q > 0.05


Инцидент возникает в случае, если:


A = ALERT
B = ALERT
C = NORMAL


Булево выражение:


(A == ALERT) && (B == ALERT) && (C == NORMAL)




### 3. Компоненты инфраструктуры

В программе анализируются компоненты:

A, B, C.

Для каждого компонента будет храниться последовательность его измерений.

На основе текущего и предыдущего значения будет вычисляться показатель Q , после чего компоненту будет присваиваться состояние NORMAL или ALERT.



### 4. Формат исходных данных

Исходные данные будут считываться из файла.

Формат одного измерения:


T;A;X


где:

T - номер отсчёта;

A - код компонента;

X - значение показателя.

Пример:


1;A;24.5;2;A;25.1;3;A;26.0
